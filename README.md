# BounceOrBreak

## 📋 Project Information

**Unity Version**: 6000.2.14f1

## 🚀 Initial Setup

### Apply Script Template

To follow the project's coding conventions, apply the custom script template.

**Windows**:
```
Unity\Hub\Editor\6000.2.14f1\Editor\Data\Resources\ScriptTemplates\81-C# Script-NewBehaviourScript.cs.txt
```

Replace the file at the above path with `/Documents/81-C# Script-NewBehaviourScript.cs.txt`.

**How to Apply**:
1. Navigate to the `ScriptTemplates` directory in your Unity installation folder
2. Open `81-C# Script-NewBehaviourScript.cs.txt` with administrator privileges
3. Replace the content with `/documents/81-C# Script-NewBehaviourScript.cs.txt`
4. Save and test by creating a new script in Unity
