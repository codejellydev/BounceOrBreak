# Changelog

All notable changes to this project are recorded here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.4] - 2026-10-20

- Added a restart button to the pause menu
- You can now clear your best score in the settings
- Smoother egg movement and more reliable bounces
- Added in-app notices and a reminder when an update is available

## [0.1.3] - 2026-10-10

- First public release.

## [0.1.2] - 2026-09-22

- Added a loading screen and a pause button
- Shortened large scores, fixed the settings window
- Reduced the app size

## [0.1.1] - 2026-09-18

- Press back during a run to pause. You can resume or return to the lobby.
- Added a home button to the game over screen.
- The game now pauses automatically when you leave the app.

## [0.1.0] - 2026-09-16

- First closed test build.
